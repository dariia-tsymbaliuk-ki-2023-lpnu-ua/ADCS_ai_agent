## Опис проєкту

Автономний агент **Build Engineer**, що створює кросплатформний проєкт Hello World, конфігурує віртуальне середовище `venv`, налаштовує юніт-тести на `pytest`, скрипти збірки `scripts/ci.sh` (Linux/macOS) та `scripts/ci.bat` (Windows), а також конфігурацію GitHub Actions з матрицею операційних систем (Ubuntu, Windows, macOS).

## Запуск агента в Cursor

1. Відкрийте корінь репозиторію в Cursor (`File → Open Folder...`).
2. Відкрийте панель Composer (`Ctrl+I` / `Cmd+I`) і переконайтеся, що вибрано режим **Agent**.
3. У полі введення наберіть `@prompts/init.prompt.md` і виберіть файл зі списку, щоб прикріпити його як контекст.
4. Додайте коротку команду, наприклад:

   ```text
   @prompts/init.prompt.md Виконай інструкції з цього промпту.
   ```

5. Натисніть `Enter` і підтверджуйте дії агента (створення файлів, запуск команд) за потреби.

Після завершення роботи агента перевірте результат локально:

```bash
# Linux / macOS
./scripts/ci.sh
```

```bat
:: Windows
scripts\ci.bat
```
